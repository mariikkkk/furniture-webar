# Интерактивная WebAR инструкция по сборке мебели

Прототип показывает сборку демонстрационного табурета. В 3D можно вращать модель и проходить этапы сборки вперёд и назад. На шаге с крепежом сцена выделяет винты A1 и отверстия, а кнопка «Повторить» заново показывает движение.

## Запуск

```sh
npm ci
npm run dev
```

Откройте [локальную страницу](http://127.0.0.1:5173/). Команда `npm run build` создаёт статическую сборку в `dist/`. Для проверки AR откройте [опубликованную страницу](https://mariikkkk.github.io/furniture-webar/) в Chrome на Android с сервисами Google Play для AR. Нажмите «Открыть в AR» и выберите место для модели. Если браузер не поддерживает WebXR, инструкция доступна в 3D.

## Как читать код

- `src/main.js` связывает кнопки с номером шага и передаёт ход анимации в сцену.
- `src/steps.js` содержит названия шагов, инструкции и сведения о крепеже.
- `src/assembly.js` создаёт демонстрационные детали и вычисляет их положения для каждого момента анимации.
- `src/preview.js` показывает ту же модель в 3D и позволяет её вращать.
- `src/webxr.js` запускает WebXR, ищет горизонтальную поверхность и размещает модель.

Модель создаётся из геометрии Three.js. Для работы с моделью из Blender её нужно экспортировать в `.glb`, сохранить отдельные детали и задать для них положения в шагах сборки.
